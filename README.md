# Clip Station - AI Video Clipping Platform

A comprehensive AI-powered video clipping platform for content creators, supporting both gaming/streaming content and podcast workflows. Built with FastAPI, yt-dlp, and faster-whisper for automated short-form content generation.

## Overview

This project provides two main components:

- **GTA ClipForge** - Gaming/stream clip operations tool
- **Clip Operations Center (clip_it)** - Multi-brand AI Video Clipping Platform

## Features

- Automated YouTube/Twitch/VOD downloading via yt-dlp
- AI-powered moment detection using whisper transcription
- FFmpeg-based video editing and rendering
- FastAPI dashboard with real-time progress tracking
- Multi-brand configuration (GTA gameplay, Podcast workflows)
- YouTube and Instagram publishing APIs
- SQLite database for clip management

## Quick Start

### Prerequisites

- Python 3.10+ (3.12 recommended)
- FFmpeg with libass support (for captions)
- Git

### Setup

```bash
# Clone the repository
git clone https://github.com/Sinusoidal-Meow/Clipper_Station.git
cd Clipper_Station

# Install dependencies (after creating venv)
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# Copy .env.example files to .env files
# in respective project directories:
# - .clip_it/.env.example -> .clip_it/.env
# - .GTA/.env.example -> .GTA/.env

# Generate encryption key:
.\.venv\Scripts\python.exe -m clipops gen-key
```

### Running

```bash
# GTA ClipForge (port 8800)
.\.venv\Scripts\python.exe -m uvicorn clipforge.server:app --host 127.0.0.1 --port 8800

# Clip Operations Center (port 8765)
.\.venv\Scripts\python.exe -m clipops serve
```

## Usage

### GTA ClipForge CLI

```powershell
# Process a VOD
.\.venv\Scripts\python.exe -m clipforge run "URL" --brand gta --clips 5

# Connect YouTube account
.\.venv\Scripts\python.exe -m clipforge connect youtube --brand gta

# List clips
.\.venv\Scripts\python.exe -m clipforge list --brand gta

# Generate encryption key
.\.venv\Scripts\python.exe -m clipforge gen-key
```

### Clip Operations Center CLI

```bash
# Process a video for GTA clips
.\.venv\Scripts\python.exe -m clipops run "URL" --brand gta --clips 5 --export-all

# Process podcast content
.\.venv\Scripts\python.exe -m clipops run "URL" --brand podcast --clips 3

# List available clips
.\.venv\Scripts\python.exe -m clipops list --brand gta

# Connect YouTube account
.\.venv\Scripts\python.exe -m clipops connect youtube --brand gta --label "My Channel"

# Generate encryption key
.\.venv\Scripts\python.exe -m clipops gen-key
```

## Environment Variables

Refer to `.env.example` templates in each project directory:

- `TOKEN_ENCRYPTION_KEY` - Generated via `gen-key` command
- `YOUTUBE_CLIENT_ID` / `YOUTUBE_CLIENT_SECRET` - Google Cloud OAuth credentials
- `GEMINI_API_KEY` - Optional: Google Gemini for enhanced metadata
- `PUBLIC_MEDIA_BASE_URL` - Cloudflare Tunnel URL for Instagram publishing
